# Interactive Course: Advanced Game AI & Combat Systems in UE5

The full interactive course has been created as an HTML application.

**Open `entire_course.html` in a browser to access the course.**

## Features

- 12-week curriculum with expandable lessons, code examples, and diagrams
- Interactive modules: Response Curve Visualizer, I-Frame Timeline, Damage Pipeline Calculator
- Quizzes after each week with automatic grading
- Midterm Exam (Weeks 1-6) and Final Exam (all weeks)
- Progress tracking with localStorage persistence
- Complete systems reference sheet
- Dark theme optimized for developer comfort
